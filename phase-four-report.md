## Limitations and remaining work
- Growth counts first recorded approval, not every later reapproval; old records fall back to review dates and missing historical dates cannot be reconstructed.
- Reports use application submission dates for current-status university totals; approval growth is filtered by approval event date independently.
- States represented count states recorded on applications, clearly explained in the interface.
- Matching confirms all currently unmatched applications in the exact typed-name group. Existing-university search returns up to 12 matches; refine search to locate a record.
- Directory intentionally starts empty; add real universities, then verify and match real applications after review.
- Existing public privacy/community-rules/password recovery pages were preserved to avoid breaking registration consent/recovery despite the request's narrower public-page list.
- Before representatives can be appointed: design a separate secure role system, university-scoped database policies, privacy/access tests and obtain explicit founder approval. No current preparation grants permissions.
